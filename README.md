# 📊 SQL Advanced Analytics

## 📌 Project Overview

This repository showcases my learning and practical implementation of **Advanced SQL Analytics using Microsoft SQL Server**.

I created and practised SQL queries to strengthen my analytical thinking, improve query-writing skills, and understand how SQL can be used to solve real-world business problems.

I have organized my SQL queries, datasets, and query output screenshots into separate folders to document my learning journey and showcase my SQL knowledge through practical examples.

## 🎯 Project Objectives

- Strengthen advanced SQL querying skills.
- Analyze sales trends and business performance.
- Understand cumulative and comparative analysis.
- Identify category-wise sales contributions.
- Perform customer and product segmentation.
- Create reusable SQL views for reporting and analysis.

## 📈 Analytical Topics Covered

### 1. 📅 Change Over Time Analysis
- Analyze yearly and monthly sales trends.
- Track total sales, customers, and quantities.
- Apply SQL date functions.

### 2. 📊 Cumulative Analysis
- Calculate monthly sales.
- Generate running totals.
- Calculate cumulative averages.
- Apply window functions.

### 3. 📈 Performance Analysis
- Compare product sales with average performance.
- Analyze Year-over-Year (YoY) growth.
- Compare current and previous-year performance.

### 4. 🧩 Part-to-Whole Analysis
- Analyze category-wise sales contributions.
- Calculate percentage contribution to overall sales.
- Identify high-performing categories.

### 5. 👥 Data Segmentation
- Segment products based on cost ranges.
- Group customers into VIP, Regular, and New categories.
- Analyze customer spending behaviour.

## 📑 SQL Reporting Views

**Customer Report – `gold.report_customers`**

- Customer information and age groups.
- Total orders and sales.
- Total quantity and products purchased.
- Customer segmentation.
- Average Order Value (AOV).
- Average Monthly Spend.

**Product Report – `gold.report_products`**

- Product and category information.
- Total sales and quantity sold.
- Total orders and unique customers.
- Product performance segmentation.
- Average Selling Price.
- Average Order Revenue.
